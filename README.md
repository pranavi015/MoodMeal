MoodMeal – Emotion-Driven Healthy Eating Companion

Frontend: mood-meal-web.vercel.app/
Backend API: https://mood-meal-server.vercel.app/

Features
-  Meal logging with mood tracking
-  Personalized insights and patterns
-  Craving swap suggestions
-  Achievement system
-  Curated meal feed

Tech Stack
- Frontend: React.js, Vite, TailwindCSS
- Backend: Node.js, Express.js, Prisma
- Database: MySQL (Aiven)
